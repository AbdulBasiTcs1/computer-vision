# Learning Path

## Stage 1: Image fundamentals

Practice reading and saving images, inspecting shape and data type, resizing, cropping, drawing, and converting between BGR and grayscale.

## Stage 2: Image processing

Learn blur, thresholding, edge detection, morphology, contours, histograms, and perspective transforms. Build small programs that solve one controlled visual problem.

## Stage 3: Video and cameras

Use `cv2.VideoCapture`, process frames in a loop, control frame rate, release resources, and save output video. Add keyboard controls and graceful exits.

## Stage 4: Detection and tracking

Study template matching, feature matching, optical flow, background subtraction, object trackers, and the difference between detection and tracking.

Try the [Hough line and circle detection and crowd face detection lesson](../1-Getting-Started-With-OpenCV/README.md) for edge-based geometry and a separate learned face detector.

## Stage 5: Geometry and calibration

Learn camera distortion, intrinsic parameters, pose, homographies, stereo vision, and how pixel measurements relate to the physical world.

## Stage 6: Deep learning integration

Use a well-tested pretrained model, understand its input and output format, measure precision and recall, and keep preprocessing identical between training and inference.

## Project ideas

- Document scanner with perspective correction
- Webcam motion detector that saves events
- Coin or object measurement tool with a known reference size
- Lane-marking visualizer for recorded road video
- Color-based sorting assistant for a fixed camera

For every project, record the input assumptions, failure cases, measured performance, and privacy impact.
